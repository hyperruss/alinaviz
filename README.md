# Лендинг частного рекрутера

Одностраничный адаптивный сайт Алана Черткоева для презентации услуг по подбору персонала в HoReCa.

## Запуск

```bash
npm install
npm run dev
```

Продакшен-сборка:

```bash
npm run build
```

Готовые файлы появятся в папке `dist`.

Проект также может публиковаться на GitHub Pages напрямую из корня ветки: пути к стилям, скрипту и favicon сделаны относительными и работают внутри подпапки репозитория.

## Обязательно заменить перед публикацией

Все значения находятся в `index.html` и легко находятся поиском:

- `+7 (000) 000-00-00` и `+70000000000` — номер телефона и ссылка WhatsApp;
- `@username` и `https://t.me/username` — Telegram;
- `hello@example.ru` — email;
- `Ваш город / регион` — география работы;
- «Алан Черткоев» — проверить точное написание ФИО;
- модель оплаты «для кандидатов бесплатно, услуги оплачивает заведение-партнёр» — подтвердить перед публикацией.

Названия заведений намеренно не указаны: их стоит добавлять только после согласия партнёров.
